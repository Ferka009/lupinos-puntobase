# Spacing System — Lupinos

## Introducción

El espacio es una parte fundamental de la identidad visual de Lupinos.

Así como una buena mesa necesita equilibrio entre cada elemento, una buena experiencia digital necesita espacio para que cada detalle pueda apreciarse.

Nuestro sistema de espaciado busca transmitir:

- Calma.
- Elegancia.
- Claridad.
- Cuidado.

El espacio no es vacío.

El espacio es parte de la experiencia.

---

# Filosofía del espacio

En Lupinos creemos que:

> "Lo importante necesita lugar para respirar."

Por eso evitamos interfaces saturadas.

Cada elemento debe tener una razón para existir y suficiente espacio para ser apreciado.

---

# Unidad base

Nuestro sistema utiliza una escala basada en múltiplos de 4px.

La unidad base es:

**4px**

Esto permite consistencia y facilidad de mantenimiento.

---

# Escala de espaciado

## XS — Detalles pequeños

4px

Uso:

- Separación entre iconos y texto.
- Pequeños ajustes internos.
- Elementos relacionados.

---

## S — Relación cercana

8px

Uso:

- Etiquetas.
- Botones internos.
- Elementos de navegación.

---

## M — Respiración funcional

16px

Uso:

- Padding interno.
- Separación entre elementos relacionados.
- Textos y botones.

---

## L — Separación importante

24px

Uso:

- Grupos de contenido.
- Cards.
- Bloques relacionados.

---

## XL — Ritmo visual

32px

Uso:

- Separación entre secciones pequeñas.
- Componentes principales.

---

## XXL — Espacio protagonista

48px

Uso:

- Secciones importantes.
- Bloques de contenido destacados.

---

## XXXL — Experiencia premium

64px - 96px

Uso:

- Hero.
- Momentos Lupinos.
- Separaciones entre grandes secciones.

---

---

# Tipografía y espacio

El espacio siempre acompaña a la jerarquía.

Un título importante necesita:

- Más tamaño.
- Más aire.
- Más presencia.

Un texto secundario necesita:

- Menos peso.
- Más cercanía.

---

# Principio de agrupación

Elementos relacionados deben estar cerca.

Elementos diferentes deben tener separación.

Ejemplo:

Correcto:

Producto

↓

Precio

↓

Botón

Incorrecto:

Producto

----------------

Precio

----------------

Botón

El espacio comunica relación.

---

# Espacio como elemento emocional

En Lupinos evitamos llenar cada espacio disponible.

Una página premium no intenta decir todo al mismo tiempo.

Selecciona lo importante.

Lo presenta.

Y permite disfrutarlo.

---

# Errores a evitar

No utilizar:

✗ Espaciados arbitrarios.

✗ Elementos demasiado juntos.

✗ Secciones sin respiración.

✗ Diseños cargados.

✗ Diferentes escalas sin intención.

---

# Regla de oro

Antes de aprobar una composición preguntamos:

> ¿Esta interfaz se siente como una mesa bien preparada?

Si la respuesta es sí, pertenece a Lupinos.

Si se siente apurada o saturada, necesita más espacio.
