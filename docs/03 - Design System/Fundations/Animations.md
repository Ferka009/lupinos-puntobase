# Animations System — Lupinos

## Introducción

Las animaciones de Lupinos tienen como objetivo transmitir cuidado, tranquilidad y calidad.

No utilizamos movimiento para sorprender.

Utilizamos movimiento para guiar.

Cada transición debe sentirse natural, elegante y humana.

---

# Filosofía de movimiento

Lupinos se mueve como una experiencia artesanal.

Con calma.

Con intención.

Sin apuro.

La interfaz debe transmitir la misma sensación que una cocina donde cada detalle está cuidado.

---

# Principios de animación

## 1. Suave antes que llamativo

Las animaciones deben ser:

✓ Naturales  
✓ Discretas  
✓ Fluidas  
✓ Elegantes  

Evitar:

✗ Movimientos bruscos  
✗ Efectos exagerados  
✗ Animaciones innecesarias  

---

# 2. Cada movimiento tiene un propósito

Una animación debe ayudar a comprender algo.

Ejemplos:

Un producto agregado a Mi Mesa.

Un cambio de estado.

Una transición entre secciones.

Una confirmación de acción.

Nunca animamos solamente porque podemos hacerlo.

---

# 3. Ritmo tranquilo

La velocidad de Lupinos debe sentirse:

Calmada.

Segura.

Cuidada.

No buscamos una experiencia rápida y agresiva.

Buscamos una experiencia agradable.

---

# Curvas de movimiento

Preferimos movimientos suaves.

Utilizamos:

- Ease-out para entradas.
- Ease-in-out para transiciones.
- Movimientos naturales.

Evitar:

- Rebotes excesivos.
- Efectos elásticos.
- Cambios bruscos.

---

# Duraciones recomendadas

## Microinteracciones

100ms - 200ms

Uso:

- Hover.
- Cambio de iconos.
- Estados pequeños.

---

## Interacciones normales

250ms - 400ms

Uso:

- Botones.
- Cards.
- Modales.
- Cambios de estado.

---

## Transiciones importantes

500ms - 800ms

Uso:

- Hero.
- Cambios entre grandes secciones.
- Aparición de contenido emocional.

---

# Animaciones de componentes

## Botones

El botón debe responder suavemente.

Ejemplos:

Hover:

- Cambio leve de color.
- Pequeña elevación.

Click:

- Confirmación inmediata.

Nunca:

- Saltos.
- Escalas exageradas.

---

## ProductCard

La tarjeta de producto debe sentirse cuidada.

Estados:

### Entrada

Aparición progresiva.

Puede incluir:

- Opacidad.
- Pequeño desplazamiento vertical.

### Hover

Movimiento mínimo:

- Elevación suave.
- Mayor presencia.

### Agregado a Mi Mesa

Debe generar una sensación positiva.

Ejemplo:

- Confirmación visual.
- Cambio de estado.
- Pequeño feedback.

---

# Hero

El Hero es el primer momento Lupinos.

Debe sentirse como abrir la puerta de la marca.

Animaciones posibles:

- Aparición suave del texto.
- Entrada lenta de imagen.
- Movimiento mínimo de elementos.

Evitar:

- Carruseles automáticos.
- Efectos protagonistas.

---

# Scroll Experience

El desplazamiento debe sentirse natural.

Usamos animaciones para:

- Revelar contenido.
- Crear ritmo.
- Guiar la atención.

No usamos:

- Parallax excesivo.
- Movimiento constante.
- Distracciones.

---

# Estados importantes

## Loading

Debe transmitir cuidado.

Evitar:

"Esperando..."

Preferir:

Una transición suave que mantenga la sensación de marca.

---

## Confirmaciones

Cuando el usuario realiza una acción importante:

Ejemplo:

"Producto agregado a Mi Mesa."

La interfaz debe reconocerlo.

La persona debe sentir:

"Mi elección fue registrada."

---

# Accesibilidad

Las animaciones deben respetar las preferencias del usuario.

Debe existir soporte para:

`prefers-reduced-motion`

Las personas que prefieran menos movimiento deben tener una experiencia cómoda.

---

# Animaciones que evitamos

No utilizar:

✗ Animaciones infinitas.

✗ Elementos flotando constantemente.

✗ Efectos de casino.

✗ Transiciones lentas que retrasen acciones.

✗ Movimiento sin propósito.

---

# Personalidad del movimiento

Si Lupinos fuera una persona:

No entraría corriendo a una habitación.

Entraría tranquila.

Prepararía la mesa.

Ordenaría cada detalle.

Y recién después invitaría a sentarse.

Así debe sentirse la interfaz.

---

# Regla de oro

Antes de agregar una animación preguntamos:

> ¿Este movimiento transmite cuidado o solamente llama la atención?

Si transmite cuidado, pertenece a Lupinos.

Si solamente busca impresionar, no lo necesitamos.
