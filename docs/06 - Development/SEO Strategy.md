# SEO Strategy

**Version:** 1.0

**Status:** Active

**Last Updated:** 03/08/2026

---

# Objetivo

Definir la estrategia de posicionamiento orgánico para Lupinos 2.0.

El objetivo es aumentar la visibilidad del emprendimiento en buscadores, especialmente para búsquedas relacionadas con pastas artesanales, productos frescos y experiencias gastronómicas en Luján y alrededores.

---

# Filosofía

El SEO de Lupinos no busca atraer cualquier tráfico.

Busca atraer personas que valoran:

- productos artesanales;
- calidad gastronómica;
- ingredientes seleccionados;
- experiencias compartidas;
- comida hecha con dedicación.

Cada página debe responder una intención real del usuario.

---

# Objetivos principales

## Descubrimiento

Lograr que nuevos clientes encuentren Lupinos mediante búsquedas orgánicas.

Ejemplos:

- pastas artesanales Luján;
- fábrica de pastas Luján;
- ravioles caseros;
- sorrentinos artesanales;
- pastas frescas Buenos Aires.

---

## Confianza

Transmitir desde Google:

- calidad;
- profesionalismo;
- cercanía;
- identidad artesanal.

---

## Conversión

Transformar visitas en acciones:

- conocer productos;
- crear Mi Mesa;
- enviar pedido por WhatsApp.

---

# SEO técnico

Lupinos 2.0 debe implementar:

- Metadata completa.
- Open Graph.
- Twitter Cards.
- Sitemap.
- Robots.txt.
- URLs optimizadas.
- Structured Data.
- Canonical URLs.

---

# Metadata

Cada página debe definir:

- title;
- description;
- keywords relevantes;
- Open Graph.

---

## Title

Debe incluir:

- marca;
- categoría;
- ubicación cuando sea relevante.

Ejemplo:

```text
Lupinos | Pastas Artesanales en Luján
```

---

## Description

Debe comunicar:

- qué ofrecemos;
- diferenciación;
- ubicación;
- propuesta de valor.

Ejemplo:

```text
Pastas artesanales elaboradas en Luján con ingredientes seleccionados y recetas pensadas para compartir momentos especiales.
```

---

# Arquitectura SEO

La estructura de URLs debe ser clara.

Ejemplo futuro:

```
/
Landing principal

/carta
Catálogo de productos

/colecciones/[slug]
Colecciones emocionales

/contacto
Información de contacto
```

# Product SEO

Cada producto debe tener información optimizada.

Debe incluir:

- nombre;
- descripción;
- categoría;
- ingredientes;
- imágenes;
- disponibilidad.

Ejemplo:

```text
Raviolones de calabaza asada

Pasta artesanal rellena elaborada con calabaza seleccionada y especias naturales.
```

---

# Imágenes SEO

Todas las imágenes deben:

- utilizar formatos optimizados;
- tener nombres descriptivos;
- incluir alt text.

Ejemplo:

Incorrecto:

```
IMG_1234.webp
```

Correcto:

```
raviolones-calabaza-artesanales.webp
```

---

## Product

- precio.

---

## Review

Para futuras reseñas.

# Performance y SEO

El posicionamiento depende también de la experiencia.

Mantener:

- carga rápida;
- imágenes optimizadas;
- buena accesibilidad;
- Core Web Vitals saludables.

---

# Mobile SEO

La experiencia móvil tiene prioridad.

Validar:

- botones accesibles;
- textos legibles;
- navegación simple;
- velocidad.

---

# URLs

Las rutas deben ser:

- cortas;
- descriptivas;
- fáciles de entender.

Correcto:

```
/colecciones/familia
```

Evitar:

```
/page?id=123
```

---

# SEO durante desarrollo

Cada nueva funcionalidad debe considerar:

Antes:

- intención del usuario;
- estructura;
- contenido.

Durante:

- semántica HTML;
- metadata;
- rendimiento.

Después:

- indexación;
- validación.

# Métricas

Objetivos:

- Lighthouse SEO ≥ 95.
- Core Web Vitals saludables.
- Crecimiento orgánico progresivo.
- Mayor visibilidad local.

---

# Definition of Done

Una funcionalidad cumple SEO cuando:

- tiene estructura semántica;
- contiene metadata correcta;
- está optimizada para buscadores;
- mantiene la experiencia de usuario.

---

# Filosofía final

El SEO de Lupinos no consiste en aparecer primero.

Consiste en que cuando alguien busque una experiencia de pastas artesanales, encuentre una marca que ya transmite cuidado, tradición y ganas de compartir.

El mejor posicionamiento nace de construir algo que las personas realmente quieren encontrar.
