# 🍝 Lupinos – Pastas Artesanales

Sitio web oficial de **Lupinos**, un emprendimiento dedicado a la elaboración de pastas artesanales y prepizzas de alta calidad.

## 🌐 Tecnologías

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## ✨ Características

- Diseño moderno y responsive
- Hero con imagen de alto impacto
- Catálogo de productos
- Navegación fluida
- Optimización para SEO
- Componentes reutilizables

## 📁 Estructura

```
app/
components/
public/
```

## 🚀 Instalación

```bash
git clone https://github.com/Ferka009/lupinos-puntobase.git
cd lupinos-puntobase
npm install
npm run dev
```

La aplicación estará disponible en:

```
http://localhost:3000
```
